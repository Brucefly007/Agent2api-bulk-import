# 常见问题

## 装完没看到按钮？

浏览器强刷一次（Ctrl+F5）。面板是单页应用，`index.html` 变了但页面没重载时看不到新脚本。

确认装好了：

```bash
python install.py --status
```

应输出 `插件文件：13138 字节` 和 `index.html 注入：已注入`。

## 升级面板后按钮消失了？

插件写在容器的可写层，镜像更新/容器重建会覆盖 `/app/ui`。重跑：

```bash
python install.py
```

`install.py` 是幂等的，备份也只在第一次生成。

## 导入报「导入内容必须是 JSON 对象」

说明 body 被发成了裸数组。本插件已经按 `{"accounts": [...]}` 发送，如果你是自己调接口，注意要包一层对象。

## 导入报「缺少 accounts 数组」

说明包了对象但键名不对（例如用了 `items`、`data`、`list`）。只认 `accounts`。

## 导入成功但账号查不了余额？

这是凭证本身不完整，不是导入的问题。比如某些提供商的 `accessToken` 必须由官方客户端换取，
手工抓到的只是授权码。导入时预览区会显示识别结果，但币值类字段是否可用取决于凭证质量。

## 会不会覆盖我已有的账号？

同 `provider` + 同身份（通常是 `uid`）会**更新**已有记录，不会产生重复；不同身份则新增。
建议先手工备份面板数据再批量导入。
